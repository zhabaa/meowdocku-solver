# Бот для решения Meowdoku

## Правила игры

Поле `N×N` цветных клеток, кошек ровно `N`. 

Требования:

- одна кошка на цвет,
- одна кошка на строку,
- одна кошка на столбец,
- кошки не касаются: все 8 соседних клеток свободны

Клетки одного цвета всегда образуют одно связное пятно: соприкасаются они сторонами, а не углами.

Управление: одиночный тап ставит крестик, двойной — котика. Крестики - скип.

## Запуск

```
main.py                # один уровень
main.py --levels 5     # пять уровней
main.py --levels 0     # без ограничения
main.py --dry-run      # показать решение, не тапать
main.py --image путь   # разобрать сохранённый скриншот
main.py --verbose      # подробный лог в консоль
main.py --log путь     # куда писать лог
```

Телефон подключается по USB, отладка включается в настройках разработчика.

Лог всегда пишется в `img/tmp/bot.log`, флаг `--verbose` включает ещё и консоль.


## Игровой цикл

1. Сделать скриншот 
2. Определить тип экрана
3. Решить единственным способом и поставить кошек,
4. Пройден
5. Одиночный тап в оранжевую кнопку на экране лидерборда
6. Одиночный тап на кнопку следующего уровня
7. Неизвестно - переснять и попробовать снова.

Переходы: тап, дальше снимок раз в секунду. Пока тип экрана не сменился, тап повторяется в ту же точку. 

С котиками то же самое: двойной тап, ждём появления котика в нужной клетке, не появился — повторяем в ту же точку.

## Пороги

Все значения в `meowdoku_bot/config.py`

| Порог | Значение | Почему |
|---|---|---|
| `board.size_tolerance` | 0.15 | внутри поля клетки отличаются на пиксель, посторонние квадратики — на десятки. При `0.3` проходил лишний квадрат `70×70` рядом с клетками `94×95` |
| `cat.dark_ratio` | 0.15 | у котиков 44–52% тёмных пикселей, у крестика `0`. Запас трёхкратный |
| `screen.button_min_fill` | 0.75 | настоящая кнопка залита на 95%, слипшиеся жёлтые клетки — на 45% |
| `screen.button_min_aspect` | 2.0 | кнопка шире высоты в `4.7` раза, слипшиеся клетки вдвое выше ширины |
| `timing.min_board_size` | 4 | на переходах ловились кадры, читающиеся как поле `1×1` |

| `--levels 3` | - | 3 | 17 | 0 | 0 |
| `--levels 0` | 18м | 47 | 429 | 0 | 0 |

За прогон попадались поля `8×8`, `9×9` и `10×10` и уровни с уже стоящими котиками.

Ни одного повторного тапа и ни одного отказа солвера: поле либо читается однозначно, либо бот переснимает экран.
